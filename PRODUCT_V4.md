# Neta Telegram v4 — product freeze

## Позиціонування

**Neta — коротка підготовка до НМТ, яка накопичує цінність між заняттями.**

Ядро — **Neta Memory**:

- запам’ятовує конкретні помилки;
- повертає слабкі навички в наступні Daily;
- змішує повторення з новими питаннями;
- показує сильніші навички й фокус;
- не видає коротку вправу за достовірний рівень або бал НМТ.

## Перші 60 секунд

`/start` → чітка обіцянка → 3 curated питання → перший профіль → Neta Memory → перший Daily.

Довгі A–D варіанти відображаються повністю у повідомленні, а кнопки відповіді компактні. Технічні `Task 2/Task 6` не показуються учню.

## Що дає відчуття завершеного продукту

- один візуальний стиль без зайвих стікерів;
- короткі feedback-блоки `✓ Правильно` / `↻ На повторення`;
- Daily result: результат, точність, сильніша навичка, повторення, streak;
- одна основна наступна дія — прогрес;
- канал як корисний другий шар, а не gate;
- добровільні reminders і leaderboard;
- окремий privacy screen;
- чесний course-interest funnel без fake scarcity.

## Growth loop

Traffic → bot intro → Daily habit → progress/Neta Memory → channel → referral → course interest.

Канал `@neta_nmt` дає контент між заняттями. Бот не вимагає підписки для доступу до навчання.

## Monetization

У Telegram v4 немає агресивного Premium CTA. Legacy paid rights та payment history збережені.

Монетизаційний сигнал зараз: `Про курс` → `Мені цікаво`. Наступний великий monetization surface — Web/structured course після перевірки retention та попиту.

## Freeze rule

Після live smoke-test не додавати режими просто заради кількості функцій. Міняти Telegram-ядро лише якщо:

1. є blocker/bug;
2. funnel metric показує конкретне просідання;
3. зміна потрібна для спільної Telegram/Web архітектури.
